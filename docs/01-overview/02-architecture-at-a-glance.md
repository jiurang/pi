# 一图看懂全局

> 这是整套文档的第 1 层：**大的面**。读完这一篇，你应该能在不看代码的情况下说出"Pi 是什么、分几层、数据怎么流动"。不需要记住任何函数名。

## Pi 在做什么

一句话：**Pi 让一个 LLM（大模型）在一个循环里干活——"想一下 → 用工具改代码/跑命令 → 看到结果 → 再想"——并且整个过程可以被记住、被压缩、被恢复。**

你输入一句中文指令，Pi 会把这句话交给大模型，大模型可能说"我需要先看看这个文件"，然后 Pi 帮你读文件、把内容送回给大模型，大模型再决定下一步……直到任务完成。

## 全局分层（一张图）

把 Pi 想象成一辆**自动驾驶的车**：

```
┌─────────────────────────────────────────────────────────────┐
│ 整车（pi-coding-agent）── 你驾驶的界面                         │
│   方向盘/仪表盘 = 终端 UI（pi-tui）                            │
│   行车电脑      = AgentSession（管理一次对话、记忆、工具）       │
├─────────────────────────────────────────────────────────────┤
│ 发动机（pi-agent-core）── 决定怎么开                           │
│   引擎循环      = agent-loop（想→做→看结果→再想，直到做完）      │
│   变速箱/底盘   = 会话存储、压缩、技能、工具                     │
├─────────────────────────────────────────────────────────────┤
│ 油箱/燃料（pi-ai）── 大模型本身                               │
│   加油枪        = provider 适配器（OpenAI / Anthropic / ...）   │
│   油量表        = 模型目录、鉴权（API key / OAuth）             │
└─────────────────────────────────────────────────────────────┘
```

更贴近代码的分层是这样（从左到右是"越用越底层"）：

```
你                          Pi 应用层             Pi 运行时层             Pi LLM 抽象层              大模型服务商
┌──────┐    输入    ┌────────────────┐    ┌──────────────────┐    ┌──────────────────┐     ┌──────────────┐
│ 终端  │ ────────▶ │ coding-agent   │───▶│ agent-core       │───▶│ pi-ai            │ ───▶│ OpenAI /      │
│ 用户  │ ◀──────── │ AgentSession   │◀───│ agent-loop       │◀───│ Models → provider│ ◀───│ Anthropic /   │
└──────┘    渲染    │  + TUI 界面    │    │  + 会话/压缩/工具 │    │ → 流式事件        │     │ Google / ...  │
                    └────────────────┘    └──────────────────┘    └──────────────────┘     └──────────────┘
```

每一层只和相邻层说话，层与层之间传递的是**"消息"**和**"事件流"**。

## 一条主链路（30 秒看懂数据怎么流）

```
1. 你输入 → 应用层收到
2. 应用层把"历史消息 + 你的输入 + 可用工具列表"交给运行时层
3. 运行时层的循环调用 LLM 抽象层 → 大模型流式返回回答
4. 回答的文本实时显示给你；如果大模型说"我要调 bash"，运行时层就去执行
5. 执行结果（toolResult）送回给大模型 → 大模型继续想 → 循环……
6. 每一步都被记进会话文件（JSONL），对话太长就自动压缩成摘要
7. 直到大模型说"做完了"，这一轮结束，等你下次输入
```

## 三个核心抽象（先混个脸熟）

| 抽象 | 是什么 | 类比 |
|---|---|---|
| **Model** | 一个模型的信息（哪个服务商、哪个模型 id、多少钱、多长上下文） | 一张"加油站名片" |
| **Message** | 一条消息（用户说的 / 模型说的 / 工具执行的），由内容块组成 | 一句话 + 附带附件 |
| **EventStream** | 大模型返回的"流"：字是一点点蹦出来的，Pi 用事件流接住它 | 水龙头出水，一滴一滴接 |
